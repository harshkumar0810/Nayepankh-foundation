# NayePankh Foundation - Premium UI/UX Redesign 🚀

A modern, highly responsive, and premium dark-theme redesign of the NayePankh Foundation website. This project focuses on improving user experience (UX), maximizing donation conversion rates through strategic UI elements, and providing a seamless mobile-first experience.

### 🌐 Live Demo
[Check out the live website here :](https://harshkumar0810.github.io/Nayepankh-foundation/)

---

## 🎯 Objective
The primary goal of this redesign was to transform the existing NGO website into a modern, trustworthy, and visually appealing platform. By introducing a dark theme with glassmorphism effects, smooth animations, and better typography, the website now reflects the immense value and impact of the NGO.

## ✨ Key Features

- **Premium Dark Theme:** A visually striking dark mode interface using `#0a0a0a` (Deep Charcoal) and `#f5a623` (Premium Gold) for high contrast and readability.
- **Glassmorphism UI:** Modern frosted-glass effects (`backdrop-filter`) on the navigation bar and modal overlays.
- **Immersive Mobile Menu:** A fluid slide-in mobile navigation menu designed for modern smartphone users.
- **Cinematic Scroll Animations:** Elements smoothly fade and slide up as the user scrolls, built using the `IntersectionObserver` API for maximum performance.
- **Dynamic Impact Calculator:** An interactive donation slider that instantly calculates and displays the real-world impact (meals, education kits, trees) of a donor's contribution.
- **Program Modals:** Clickable program cards that open detailed pop-ups with SVG icons and bulleted impact points.
- **High-Conversion Donate Buttons:** Custom-styled buttons with hover scale animations and gold-glow effects to encourage donations.
- **Premium 5-Column Footer:** A perfectly aligned, professional footer featuring trusted badges and custom SVG social links (like the new X logo).

## 🛠️ Tech Stack

- **HTML5:** Semantic and accessible markup.
- **Custom CSS3:** Pure, utility-driven custom CSS with Grid/Flexbox, CSS Variables, and custom media queries (No heavy CSS frameworks used).
- **Vanilla JavaScript:** Pure ES6 JavaScript for DOM manipulation, modals, sliders, and scroll animations (No jQuery).
- **Google Fonts:** 'Playfair Display' for elegant headings and 'DM Sans' for clean, modern body text.
- **FontAwesome:** Scalable vector icons for social media, UI elements, and trusted badges.

## 🚀 How to Run Locally

This project uses standard web technologies and requires no build steps or package managers.

1. Clone or download the repository.
2. Ensure all HTML files, `css`, `js`, and `assets` folders are in the same directory.
3. Simply double-click `index.html` or any other `.html` file to open it in your default web browser.
4. *(Optional)* For the best experience, run it via a local development server (like VS Code's "Live Server" extension).
