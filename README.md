# NayePankh Foundation Website

A **dark-themed, multi-page NGO website** built for **NayePankh Foundation** — a UP Govt. registered, 80G & 12A approved student-led NGO working across Uttar Pradesh since 2021.

## Pages (9 Multi-Page Application)

| Page | File | Description |
|------|------|-------------|
| Home | `index.html` | Hero, stats, impact dashboard, programs, gallery, testimonials |
| About | `about.html` | Story, milestones, certificates, team |
| Programs | `programs.html` | 6 programs with modals, volunteer form |
| Gallery | `gallery.html` | Filterable photo gallery + certificates |
| Donate | `donate.html` | Donation picker, impact calculator, donate form |
| Contact | `contact.html` | Contact form, Google Maps, FAQ, social links |
| Terms & Conditions | `terms.html` | Legal guidelines for website usage, subscriptions, and donations |
| Privacy Policy | `privacy.html` | Data protection, payment security, and privacy guidelines |
| Cancellation & Refund | `cancellation.html` | Strict no-refund policy and subscription cancellation details |

## Advanced Features

- **Dark Theme** — Black/charcoal UI with gold & blue accents from the NGO logo.
- **Smooth Scroll Animations** — Enhanced cinematic fade-up animations on scroll via IntersectionObserver.
- **5-Column Premium Footer** — Perfectly aligned footer with SVG social icons and glowing contact pills.
- **Impact Dashboard** — Animated progress bars showing program reach.
- **Donation Impact Calculator** — Interactive slider showing meals/children/trees.
- **Gallery Filters** — Filter photos by category (Education, Food, Health, etc.).
- **Hindi/English Toggle** — Language switcher with localStorage persistence.
- **Scroll Progress Bar** — Top-of-page reading progress indicator.
- **Animated Counters** — Stats animate smoothly on scroll.
- **Testimonial Slider** — Auto-rotating community stories.
- **Program Modals** — Click any program card for detailed impact info.
- **Image Lightbox** — Full-screen gallery & certificate viewer.
